# KSTL 표준 제안 작업 공간

> **이 디렉터리는 제안 작업 공간이며 발행된 KSTL 표준이 아니다.**

`rules/candidates.yaml`의 모든 규칙은 검증 전 후보이다. `normativity`는 후보가
채택될 경우 검토할 강도이며 현재 작성자에게 의무를 부과하지 않는다.

`vocabulary/entries.yaml`의 항목은 스키마와 편집 흐름을 시험하는 **형식 예시**일
뿐 승인 어휘가 아니다. `allowed_forms`와 `preferred_replacements`도 검증된 한국어
통제 어휘를 선언하지 않는다.

규칙을 받아들이려면 대상 도메인의 한국어 코퍼스 근거, 한국어·기술문서 분야
전문가 검토, 독해 및 과업 이해 평가가 필요하다. 번역 목적의 후보라면 번역 방향과
대상 시스템도 함께 검증해야 한다. 자동 검사기는 작성자나 의미 판단을 대신하지
않으며, 휴리스틱 신호는 위반 판정이 아니다.

규칙은 국어 자료로 설계한다. 제품 이름은 preo(풀어)다. 규칙 ID의 `KSTL-`
접두사는 식별자일 뿐 제품 이름이 아니다. ASD-STE100은 비교용 참고자료일 뿐이며
규칙의 근거가 아니다. 저작권이 있는 ASD-STE100 규칙 문구를 이 작업 공간에
복사하지 않는다. Issue 9 공식 사본 신청은 진행 조건이 아니다.
